## Scheduler 孤儿任务自动恢复机制

### 问题
后端重启后，running 状态的协程随进程消失，但数据库任务 status=active/paused 不变 → 僵尸任务，进度条卡死

### 修复 (task_scheduler.py)
- 新增 `_scan_orphan_tasks()`: 启动时扫描 DB 中 active/paused 任务，对比 scheduler 队列找孤儿
- 新增 `_recover_paused_task()`: paused 任务自动 advance + dag-run（安全，paused 因质量门 block 而非 mid-LLM）
- active 任务仅 SSE 通知不自动重跑（避免双花 LLM 预算）
- 关键修复: 将 `_scan_orphan_tasks()` 调用移到 `if not persisted: return` 之前（原来 Redis 为空时跳过扫描）
- 验证: 发现 26 孤儿任务，恢复 1 paused 任务成功入队
